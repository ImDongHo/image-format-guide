이미지 포맷 길잡이 만든 사람: 임동호

논문 「같은 화질에서 WebP·AVIF는 JPEG보다 얼마나 작은가」(임동호, 2026)의 결과로 만든 앱

이미지를 어떤 포맷으로 저장할까요?

이 앱은 보고서·블로그에 화면 캡처나 사진을 올리는 사람이 저장 포맷을 고를 때, 논문에서 실제로 잰 '같은 화질 기준 JPEG 대비 절감률'로 어떤 포맷이 얼마나 가벼워지는지 알려 줘서 돕습니다.

1이미지 종류를 고르세요

잘 모르겠으면 아래에 이미지를 올리거나 예시로 해 보세요. 논문과 같은 기준으로 추정합니다.

또는 예시로

이미지는 이 브라우저 안에서만 분석하고 어디에도 올리지 않습니다. 이 영역에 끌어다 놓아도 됩니다.

2원하는 화질을 고르세요

고르기 어렵다면 보통을 고르세요. 괄호 안 숫자는 논문에서 쓴 화질 점수(SSIM)로, 1에 가까울수록 원본과 똑같아 보입니다.

3지금 JPEG 용량을 넣어 보세요 (선택)

JPEG로 저장했을 때의 용량을 넣으면, 같은 화질의 WebP·AVIF가 얼마쯤 될지 계산합니다. 이미지 여러 장의 합계를 넣어도 됩니다.

추천 포맷

AVIF

    이 숫자는 어디서 왔나요

    사진 24장과 보안 실습 화면 캡처 24장을 가운데 640×400으로 자르고, SSIM 0.90·0.95·0.98을 넘는 가장 낮은 품질로 JPEG·WebP·AVIF를 만들어 크기를 비교했습니다(총 432건). 아래 표는 조건마다 이미지 24장의 절감률 중앙값입니다.

    이 결과의 한계

    • 종류마다 이미지가 24장뿐입니다.
    • 화면 캡처는 보안 실습의 터미널·콘솔 화면 위주라 문서나 일반 웹 화면에 그대로 맞지 않을 수 있습니다.
    • SSIM을 밝기 채널로만 재었고, 사람이 눈으로 본 화질 평가는 하지 않았습니다.
    • JPEG는 기본 인코더 기준입니다. mozjpeg를 쓰면 WebP의 이점이 줄 수 있습니다.
    • 품질 1에서도 목표 화질을 넘은 32건(모두 화면 캡처)은 실제 절감률을 정확히 재지 못했습니다.
