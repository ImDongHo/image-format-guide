# 이미지 포맷 길잡이

보고서·블로그에 화면 캡처나 사진을 올리는 사람이 저장 포맷을 고를 때,
10번 논문 「같은 화질에서 WebP·AVIF는 JPEG보다 얼마나 작은가」(임동호, 2026)에서 실제로 잰
'같은 화질 기준 JPEG 대비 절감률'로 어떤 포맷이 얼마나 가벼워지는지 알려 주는 앱입니다.

- 공개 주소: https://imdongho.github.io/image-format-guide/
- 만든 사람: 임동호 · https://imdongho.github.io/about-me/

## 사용자가 할 일 세 가지

1. 이미지 종류(화면 캡처 / 사진)를 고릅니다. 잘 모르면 이미지를 올리거나 예시 버튼을 누르면 논문과 같은 기준으로 추정합니다.
2. 원하는 화질(가볍게 SSIM 0.90 / 보통 0.95 / 선명하게 0.98)을 고릅니다.
3. 추천 포맷과 절감률을 확인하고, 지금 JPEG 용량을 넣어 WebP·AVIF의 예상 용량을 봅니다.

## 논문 결과를 어떻게 쓰나

| 앱의 기능 | 논문에서 가져온 것 |
|---|---|
| 추천 포맷과 절감률 | 조건 12개(종류 × 포맷 × 화질)마다 이미지 24장의 절감률 중앙값과 가운데 절반 범위 |
| 예상 용량 | 위 중앙값과 25~75% 범위를 입력한 JPEG 용량에 곱함 |
| 이미지 종류 추정 | 논문 `select_screens.py`와 같은 계산(가운데 640×400, 가장 많은 한 색 비율, 가로 밝기 차 > 40 비율). 논문 화면 캡처 24장의 한 색 비율 최솟값 35.6% 이상이면 화면 캡처 |
| 비슷한 화면 캡처 5장 | 한 색 비율이 가장 비슷한 논문 화면 캡처 5장의 실측 절감률 중앙값 (논문: AVIF 절감률과 상관 r = 0.68~0.77) |
| 주의 문구 | JPEG보다 커진 경우(화면 캡처 SSIM 0.90 WebP 3장), floor 건수, AVIF 인코딩이 약 120배 느림 |

앱의 이미지 분석이 논문과 같은 값을 내는지는 논문 화면 캡처 24장으로 확인했습니다(반올림 범위 안에서 일치).

## 내 컴퓨터에서 실행

설치할 것이 없습니다. 이 폴더를 받은 뒤 `index.html`을 브라우저로 열면 됩니다.
서버로 열고 싶다면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000 을 엽니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 |
| `app.js` | 계산과 동작 |
| `paper-results.js` | 앱이 쓰는 논문 수치 (아래 스크립트가 만듦, 직접 고치지 않음) |
| `data/savings_per_image.csv` | 논문 원자료: 이미지별 JPEG 대비 절감률 288건 |
| `data/screen_selection_log.csv` | 논문 원자료: 화면 캡처 후보 42장의 한 색 비율·윤곽 밀도와 선택 결과 |
| `tools/build_data.py` | 원자료에서 `paper-results.js`를 다시 만드는 스크립트 (`python3 tools/build_data.py`) |

## 데이터와 비밀값

- 앱의 데이터는 논문 실험의 집계값입니다. 사람에 관한 정보는 없습니다.
- 사용자가 올린 이미지는 브라우저 안에서만 분석하고 어디에도 보내지 않습니다.
- 예시 이미지는 앱이 직접 그린 그림입니다. 예시 터미널의 IP 주소는 문서용 예약 대역(203.0.113.0/24, 198.51.100.0/24)입니다.
- AI 서비스나 외부 API를 쓰지 않으므로 키나 환경 변수가 필요 없습니다.
